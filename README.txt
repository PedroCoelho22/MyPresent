# 💗 Birthday Love Website — 18th Birthday

A free, single-page birthday website with:

- 🎂 Birthday home screen
- 💗 18 Reasons Why I Love You
- 💌 Open When... letters
- ✨ Floating hearts
- 📱 Mobile-friendly design
- 🌙 Romantic dark theme
- 🚫 No paid services required

## 1. Personalize it

Open `script.js`.

At the top you will find two arrays:

- `reasons` → your 18 reasons
- `letters` → your Open When messages

Replace the example text with your own.

You can also change the title in `index.html`.

## 2. Add photos later (optional)

The current version does not require any images, so it works immediately.

If you want, you can add an "Our Memories" section later with your photos.

## 3. Publish for free with GitHub Pages

1. Create a free GitHub account.
2. Create a new repository.
3. Upload `index.html`, `style.css` and `script.js`.
4. Go to the repository's Settings → Pages.
5. Select the main branch and root folder.
6. Save.
7. GitHub will give you a free address similar to:

   https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

Then send the link to your boyfriend.

## Important

The site uses Google Fonts from the internet. If you want the site to work completely offline, replace the fonts with local/system fonts.
